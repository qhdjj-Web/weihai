# 📖 使用指南

## 第一次使用

### 1. 获取应用
- **方式A**：从 GitHub 克隆
  ```bash
  git clone https://github.com/yourusername/weihai-tour-planner.git
  ```

- **方式B**：直接下载 ZIP 文件并解压

- **方式C**：在线访问 GitHub Pages 版本

### 2. 打开应用
- Windows：右键 `index.html` → 用浏览器打开
- Mac：双击 `index.html` 或右键 → 打开方式 → 选择浏览器
- Linux：`open index.html` 或在文件管理器中打开

### 3. 允许位置权限（可选）
- 部分浏览器会提示获取位置权限
- 允许后地图会自动定位到威海

## 快速上手

### 场景1：我想自己选景点

1. **浏览景点列表**
   - 下拉列表查看所有威海景点
   - 每个景点显示图片、时间、描述、美食

2. **勾选喜欢的景点**
   - 点击复选框勾选（勾选后会变成蓝色背景）
   - 地图上对应标记会变大高亮

3. **查看地图**
   - 左侧地图显示所有景点
   - 不同颜色的标记代表不同景点
   - 点击标记查看详细信息

4. **生成路线**
   - 点击"📋 生成路线"
   - 系统整理成出行方案
   - 点击"📄 复制导出"复制到剪贴板

### 场景2：我想和朋友一起规划

#### 通过导出/导入
1. **我的电脑上**
   - 勾选景点 → 点击"💾 导出数据"
   - 选择保存位置，得到 JSON 文件

2. **发给朋友**
   - 将 JSON 文件通过微信、邮件等分享

3. **朋友的电脑上**
   - 点击"📂 导入数据"
   - 选择你分享的 JSON 文件
   - 朋友可以继续添加/修改景点

4. **再次导出合并**
   - 朋友修改完再导出
   - 你导入朋友的新数据

#### 通过 GitHub 协作
1. Fork 本项目
2. 创建分支 `feature/our-trip`
3. 修改 index.html 中的景点数据
4. 提交 PR 给主仓库

### 场景3：发现了新景点想添加

1. **点击"➕ 添加地点"**
   - 表单展开

2. **填写基本信息**
   - 景点名称：如"缆车山顶"
   - 经度(lng)：122.15（在高德地图查询）
   - 纬度(lat)：37.50

3. **上传景点图片**
   - 点击文件选择框
   - 选择本地图片
   - 点击"预览"查看效果

4. **填写其他信息**
   - 简介描述：50-100字介绍
   - 建议游玩时段：如"09:00-17:00"
   - 游玩时长：如"1-2小时"
   - 周边美食：推荐的饭食

5. **保存**
   - 点击"✓ 保存"
   - 新景点立即出现在列表和地图上
   - 数据会自动保存到浏览器

## 高级用法

### 批量导入朋友的景点

假如朋友已经添加了很多景点：

1. **朋友导出**：点击"💾 导出数据" → 保存文件

2. **你导入**：点击"📂 导入数据" → 选择朋友的文件

3. **合并显示**：所有景点都会合并到你的列表中

### 更新景点信息

1. **更换图片**
   - 点击景点右侧"🖼️换图"
   - 选择新图片
   - 自动保存

2. **修改其他信息**
   - 目前需要导出 JSON、编辑后导入
   - 或重新添加景点后删除旧的

### 修改高德地图 Key

如果默认 Key 失效或想用自己的：

1. 编辑 `index.html`
2. 找到第9行：
   ```html
   <script src="https://webapi.amap.com/maps?v=2.0&key=ee0de72a00c6122954e9e8c06f43b64d"></script>
   ```
3. 替换为你的 Key（申请链接：https://lbs.amap.com/）
4. 保存文件

### 修改默认景点

如果想编辑内置的7个景点：

1. 在浏览器中打开 index.html
2. 按 F12 打开开发者工具
3. 在 Console 输入：
   ```javascript
   console.log(JSON.stringify(spotList, null, 2))
   ```
4. 复制输出的 JSON
5. 编辑 index.html，找到 `let spotList = [` 部分
6. 用新数据替换

## 数据备份与恢复

### 定期备份
1. 每月或重要规划后，点击"💾 导出数据"
2. 保存 JSON 文件到云盘（OneDrive/Google Drive）
3. 以日期命名，如 `weihai_2026-08-11.json`

### 恢复数据
1. 使用新设备或浏览器
2. 点击"📂 导入数据"
3. 选择之前备份的 JSON 文件
4. 所有数据恢复

### 数据迁移
- **Windows 到 Mac**：导出后导入
- **Chrome 到 Firefox**：导出后导入
- **电脑到手机**：通过 JSON 文件分享

## 常见问题

### 数据突然没了怎么办？

**可能的原因**：
1. 手动清除浏览器缓存/Cookie
2. 浏览器隐私模式
3. 浏览器崩溃或系统更新

**恢复方法**：
- 如果有导出的 JSON 文件 → 直接导入
- 如果没有备份 → 遗憾的是无法恢复

**预防措施**：
- 定期导出数据备份
- 关键数据保存到云盘

### 刷新后图片变成占位符怎么办？

这通常是因为：
- 图片过大，超过了 Base64 编码的容量限制
- 浏览器缓存被清除

解决方法：
1. 重新上传较小的图片（<1MB）
2. 定期导出备份
3. 换一个浏览器看看

### 地图不显示怎么办？

可能原因：
- 网络问题，无法加载高德地图
- 高德地图 API Key 失效
- 浏览器隐私设置阻止了地图加载

解决方法：
1. 检查网络连接
2. 刷新页面重试
3. 更换浏览器尝试
4. F12 开发者工具查看是否有错误信息

### 能否在多个设备间同步？

目前不可以，因为：
- 使用的是浏览器 localStorage
- 不同设备上的浏览器数据隔离

同步方法：
1. 在设备A上导出数据 → 保存到云盘
2. 在设备B上下载 → 导入数据

## 性能和优化

### 应用加载慢怎么办？

**检查清单**：
- ✅ 刷新页面，看是否缓存问题
- ✅ 检查网络连接质量
- ✅ 关闭浏览器其他标签页
- ✅ 检查浏览器控制台是否有错误

### 景点特别多时卡怎么办？

如果添加了100个以上景点：
- localStorage 中数据会很大
- 列表滚动可能变慢

解决方法：
1. 导出数据，清除 localStorage：
   ```javascript
   // 在控制台执行
   localStorage.clear()
   ```
2. 重新导入需要的数据

### 存储空间满了怎么办？

浏览器 localStorage 通常限制 5-10MB：

解决方法：
1. 删除不需要的图片大的景点
2. 压缩图片后重新上传
3. 定期导出备份，清理本地数据
