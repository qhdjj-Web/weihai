# 🎯 功能详细说明

## 1. 景点列表面板

### 显示内容
- 景点图片（140像素高，自动裁剪）
- 景点名称（可点击高亮）
- 勾选框（选中后会勾选）
- 建议游玩时段
- 游玩时长
- 景点描述
- 周边美食推荐

### 交互功能
- **勾选**：点击复选框选中/取消景点
- **点击景点**：自动将地图定位到该景点，并高亮显示
- **换图按钮**：点击可选择本地图片更新景点图片
- **删除按钮**：仅自定义景点显示，点击可删除

## 2. 地图展示

### 地图功能
- 高德地图 Web API v2.0 驱动
- 彩色标记标注，每个景点不同颜色
- 点击标记显示景点信息窗口（包含图片、详情、美食等）
- 当前高亮景点标记更大更显眼

### 与列表的关联
- 列表中勾选 → 地图标记变大
- 列表中高亮 → 地图自动定位并放大到该景点
- 地图上点击标记 → 列表项自动高亮

## 3. 路线规划功能

### 工作流程
1. 在景点列表中勾选想去的景点
2. 点击 "📋 生成路线" 按钮
3. 系统自动整理成结构化的出行方案
4. 点击 "📄 复制导出"，将内容复制到剪贴板

### 导出格式
```
====👢 威海出行路线规划 👢====

【1. 刘公岛】
🕒 建议 08:30‑14:00 前往
⌛ 游玩时长：3‑4小时
📝 北洋水师历史纪念地，需乘船登岛...
🍲 美食：鲅鱼饺子、海鲜面...

【2. 火炬八街】
...

💡小贴士：可按地理位置顺序调整游览先后顺序
```

## 4. 添加新景点

### 表单字段
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 景点名称 | 文本 | ✓ | 最多20个字符 |
| 经度(lng) | 数字 | ✓ | 范围 120-124 |
| 纬度(lat) | 数字 | ✓ | 范围 36-38 |
| 图片 | 文件 | ✗ | JPG/PNG等格式 |
| 简介描述 | 文本 | ✓ | 景点的简要介绍 |
| 建议游玩时段 | 文本 | ✗ | 如"09:00-17:00" |
| 游玩时长 | 文本 | ✗ | 如"2-3小时" |
| 周边美食 | 文本 | ✗ | 推荐的美食 |

### 经纬度获取
- 在高德地图上右键点击获取坐标
- 或者在任何地图应用中查看坐标
- 威海范围：经度 122±2°，纬度 37±1°

### 图片建议
- 格式：JPG、PNG（推荐JPG）
- 文件大小：<5MB（过大会影响存储）
- 分辨率：1024×768 以上最佳
- 支持所有浏览器支持的图片格式

## 5. 图片管理

### 上传图片
1. 添加新景点时选择图片文件
2. 点击"预览"预看效果
3. 保存时图片自动转换为 Base64

### 更换图片
1. 每个景点右侧有"🖼️换图"按钮
2. 点击选择新图片
3. 自动保存，刷新不丢失

### 图片存储方式
- 所有图片转换为 **Base64 字符串**
- 存储在浏览器 localStorage 中
- 不需要单独的图片文件夹
- 但大图片会占用较多存储空间

## 6. 数据导出/导入

### 导出数据
- 点击 "💾 导出数据"
- 自动下载 JSON 文件
- 文件名：`威海景点_YYYY-MM-DD.json`
- 包含所有自定义景点和图片（Base64）

### 导入数据
- 点击 "📂 导入数据"
- 选择之前导出的 JSON 文件
- 自动合并景点到现有列表
- 支持批量导入多个文件

### 导出 JSON 格式
```json
{
  "exportTime": "2026/8/11 15:30:45",
  "spots": [
    {
      "name": "景点名称",
      "lng": 122.1234,
      "lat": 37.1234,
      "img": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
      "desc": "景点描述",
      "suggestTime": "建议时间",
      "playTime": "游玩时长",
      "food": "美食推荐"
    }
  ]
}
```

## 7. 数据持久化

### localStorage 存储
| Key | 内容 | 说明 |
|-----|------|------|
| `selSpot` | 数组 | 已勾选景点的索引 |
| `customSpots` | JSON | 用户添加的景点 |
| `defaultImgOverride` | JSON | 修改过的默认景点图片 |

### 存储限制
- 浏览器 localStorage：约 5-10MB/源
- 超过限制会导致保存失败
- 可定期导出数据备份

### 清除数据
- 浏览器设置 → 清除缓存/Cookie
- 或使用开发者工具删除 localStorage
- 导入 JSON 文件可恢复

## 9. 常见问题

### Q：能否跨浏览器同步数据？
A：不能。localStorage 是单浏览器的，需要手动导出/导入。

### Q：图片转 Base64 会丢失质量吗？
A：不会。Base64 是完整的二进制编码，不会损失信息。

### Q：数据会被上传到服务器吗？
A：不会。所有数据都存储在本地，完全离线。

### Q：隐私模式下能存储数据吗？
A：不能。隐私模式下 localStorage 不可用。

### Q：能更改高德地图 API Key 吗？
A：可以。编辑 index.html，找到第 8 行，替换为自己的 Key。
